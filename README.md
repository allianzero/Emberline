Emberline is a round-based tactical FPS in the browser: five attackers against five defenders in a dusk foundry yard, a Spark Charge to plant or defuse, money earned each round and spent in a buy menu, and gunfire where stopping to aim beats spraying.
## Run it
```sh
node serve.ts
```
